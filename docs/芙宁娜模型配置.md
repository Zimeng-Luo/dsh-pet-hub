# 使用你自己的芙宁娜猫猫版

适用插件：**dsh-pet-hub 0.1.2**；DSH：0.2.1-rc.3。

## 1. 更新插件

下载 [0.1.2 预编译安装包](https://github.com/Zimeng-Luo/dsh-pet-hub/raw/refs/heads/main/downloads/dsh-pet-hub-0.1.2.tgz)。在 DSH「插件 → 添加插件」填写它的本地完整路径并安装启用，随后重启 DSH。如果界面提示已有旧插件，先在插件页卸载旧版，再添加新版；插件不会主动删除 IndexedDB 资源库。

## 2. 准备你的模型文件夹

仓库的示例路径是：

```text
example/
└─ 芙宁娜猫猫版/
   ├─ 使用教程.docx
   └─ 芙宁娜猫猫版/          ← 导入这一层
      ├─ config.json
      ├─ A芙宁娜猫猫版.exe
      ├─ BongoCatUI.exe
      └─ img/
         ├─ standard/cat_model/
         ├─ keyboard/cat_model/
         └─ gamepad/cat_model/
```

如果你已经在 Windows 保存了原来的 BongoCat 文件夹，可以直接使用它。如果只有 GitHub 上的文件，先通过仓库「Code → Download ZIP」下载并解压，再找到上面标记的那层。

**不要只选择 `keyboard/cat_model`。** 键盘模型的表情引用 `../../standard/cat_model/*.exp3.json`，只复制一个子目录会缺少这些文件。插件直接读取原配置和原路径，无需修改资源或重命名编号图片。

## 3. 在 DSH 中导入

1. 点击 DSH 左下角账户菜单，进入「设置 → 桌宠」。
2. 首次使用时，在「Live2D 运行支持」导入官方 [Cubism SDK for Web](https://www.live2d.com/en/sdk/download/web/) 的 `Core/live2dcubismcore.js` 或 `.min.js`。以后会自动加载，Core 不随插件分发。
3. 在「文件夹」输入框选择同时包含 `config.json` 与 `img` 的那层目录，确认浏览器的文件导入提示。
4. 等待导入完成。下拉框会列出「芙宁娜猫猫版 · 键鼠模式」「键盘模式」「手柄模型」。原配置 `mode: 1` 默认选择键鼠模式。
5. 想用键盘模式时选择它，点击「使用」。关闭设置即可；重开 DSH 会恢复你选中的模式。

这一步加载的是你提供的芙宁娜模型，不是内置标准猫。原包中的 EXE、DLL 不会运行。

## 4. 验证互动

- 在 DSH 页面中按 A 等原配置中的按键，会显示对应的编号手部图片。
- 表情沿用 `config.json` 的 `l2d_expression` 组合键，例如「空格 + 1」对应首个表情；松开后再次触发相同组合可切回默认。
- 桌宠设置页也提供表情按钮和「恢复默认表情」。
- 触发表情组合键前，把焦点放在页面空白处或输入框；焦点停留在按钮上时，空格也会按浏览器的正常规则点击该按钮。
- 当前键鼠事件仅来自 DSH 页面；切到其他应用后继续同步敲键盘、手柄采集、原生窗口配置与音效功能尚未迁移。

## 已验证与边界

使用仓库中的真实文件验证了整包导入、三个模式的发现、键鼠与键盘模式渲染、A 键图片按下／释放、表情快捷键、键盘模式的跨目录表情引用和刷新恢复。手柄模型可显示，但不宣称已有手柄输入支持。测试在 Linux Chromium 与 DSH Web 中执行，Windows Electron 客户端仍需本机验收。

示例模型保留在用户上传的 example 目录；新版安装包只包含插件代码，不内置或复制模型素材。

## 侧栏与余额卡片

0.1.2 移除了侧栏的模型名称、管理与收起工具行。桌宠画布占据会话列表下方的一行，余额卡片保持在其下方；在「设置 → 桌宠 → 显示」控制显隐。窗口较矮时画布会按剩余空间缩短，不覆盖会话；会话列表继续独立滚动。
