# 0.1.1 — 用户芙宁娜 Mver 整包适配

- 输入是仓库 example/芙宁娜猫猫版/芙宁娜猫猫版 的原始完整文件夹，含 config.json、三种模式的模型、编号图片和跨模式表情引用。没有执行包内 EXE/DLL。
- 13 项 Node 测试通过，5 项浏览器测试通过，其中包含该用户模型的整包导入、键鼠／键盘切换、A 键图片按下／释放、Space+1 表情触发、原始 mode 默认选择、刷新恢复及模拟 0.1.0 资源索引的自动迁移。
- 修复 easy-live2d 0.4.4 的模型销毁问题：共享 Cubism 状态按拥有者计数释放，逐模型释放原生模型与 GL shader。修复前 Live2D→Live2D 切换会使新模型报 getId/setupShaderProgramForMask 错误；修复后回归用例无页面和 console 错误。
- 使用 DSH 自身插件安装命令，将最终 0.1.1 TGZ 安装进隔离的 web profile；核对安装后 client.js 哈希与本地构建一致。
- 在实际 DSH Web 0.2.1-rc.3 中，对已安装 TGZ 执行上述芙宁娜浏览器用例，通过（21.9 秒）；截图 docs/furina-example.png 来自此轮实际 DSH 页面。
- 测试环境仍是 Linux + Chromium，并非 Windows Electron 实机。手柄输入、系统全局输入和原生音频配置不在此版本验证范围。
- 模型文件没有复制到新版 TGZ，example 保持用户上传内容不变；新安装包仅包含插件代码与配置说明。


# 0.1.2 — 设置页与侧栏布局

- 侧栏移除模型名、管理／收起按钮和空资源导入按钮。所有管理操作进入宿主 settings.section 的「桌宠」页面；独立快照桥接常驻运行时，设置页切换和关闭不重建模型。
- 修复 SlotOutlet 的 display:contents 包裹，使布局规则作用于实际 footer 容器；只给该容器添加可清理的命名空间 class，不修改余额卡片的样式、内容或账户逻辑。桌宠自身 order:-1000，兼容同类余额 stack 的 order:-1，独占一行。
- 桌宠按实际侧栏剩余空间限制高度，保留会话浏览区域；会话列表继续使用宿主的独立滚动。没有绝对定位到会话列表上方的悬浮画布。
- 13 项 Node 测试通过；7 项预览浏览器测试通过（含真实标准猫与用户芙宁娜）。布局矩阵包含：SlotOutlet 有／无、240／320／420px 侧栏、850／480px 窗口高度、60 条合成会话、隐藏／显示、折叠／展开、设置标签切换、余额卡片保持宽度与颜色。
- 实际 DSH Web 0.2.1-rc.3 中，安装 TGZ 后的两项用例通过：原芙宁娜整包导入／模式切换／索引升级恢复；settings.section 接线与模拟余额／60 条会话并存，900／650／480px 窗口、折叠再展开，无页面错误。截图 docs/sidebar-layout-0.1.2.png 来自该实际 DSH。
- 余额兼容测试复现 dsh-cost-meter 的公开 footer 规则与 SlotOutlet 结构，使用合成数值，没有安装其完整业务后端或访问任何余额账户。未连接用户 Windows Electron 和其确切主题／余额插件版本。
