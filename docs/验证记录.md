# 验证记录

目标：DSH 0.2.1-rc.3。执行环境：Linux、Node 24、系统 Chromium（无头）。

- 10 项 Node 测试通过：模型引用、路径边界、ZIP 预检、Unicode、资源释放、切换竞态、通知协议和按键别名。
- 4 项浏览器测试通过：资源导入切换／持久化／折叠／通知／错误保留；真实 BongoCat Live2D；Core 缺失提示；模拟小鲸鱼只读接口。
- 使用实际 dsh plugin --profile web add 安装生成的 TGZ，通过。
- 从安装后的插件启动实际 DSH Web 0.2.1-rc.3，完整 Live2D 浏览器用例通过：首次 Core 导入、真实标准模型加载、刷新恢复、KeyA 按键图片显示／释放、切换到图片再切回 Live2D；无页面错误与 console error。
- 截图 work/dsh-live2d.png 来自已安装 TGZ 的实际 DSH 页面。

测试模型、纹理及 Core 从上游取得，仅作本地验证，未包含在 TGZ 或源码 ZIP 中。小鲸鱼桥接仅以模拟接口验证，没有连接用户的小鲸鱼插件。

未验证：Windows Electron 壳、用户示例“少女猫猫版.zip”、截图中余额卡片插件与主题组合、系统全局输入、其他桌宠运行时、完整鲸鱼功能迁移。


# 0.1.1 — 用户芙宁娜 Mver 整包适配

- 输入是仓库 example/芙宁娜猫猫版/芙宁娜猫猫版 的原始完整文件夹，含 config.json、三种模式的模型、编号图片和跨模式表情引用。没有执行包内 EXE/DLL。
- 13 项 Node 测试通过，5 项浏览器测试通过，其中包含该用户模型的整包导入、键鼠／键盘切换、A 键图片按下／释放、Space+1 表情触发、原始 mode 默认选择、刷新恢复及模拟 0.1.0 资源索引的自动迁移。
- 修复 easy-live2d 0.4.4 的模型销毁问题：共享 Cubism 状态按拥有者计数释放，逐模型释放原生模型与 GL shader。修复前 Live2D→Live2D 切换会使新模型报 getId/setupShaderProgramForMask 错误；修复后回归用例无页面和 console 错误。
- 使用 DSH 自身插件安装命令，将最终 0.1.1 TGZ 安装进隔离的 web profile；核对安装后 client.js 哈希与本地构建一致。
- 在实际 DSH Web 0.2.1-rc.3 中，对已安装 TGZ 执行上述芙宁娜浏览器用例，通过（21.9 秒）；截图 docs/furina-example.png 来自此轮实际 DSH 页面。
- 测试环境仍是 Linux + Chromium，并非 Windows Electron 实机。手柄输入、系统全局输入和原生音频配置不在此版本验证范围。
- 模型文件没有复制到新版 TGZ，example 保持用户上传内容不变；新安装包仅包含插件代码与配置说明。
